# سایت چک سیستم برای بازی (Neon GameCheck)

سایت کاملاً استاتیک (HTML/CSS/JS) و بدون نیاز به اینترنت یا نصب پکیج.

## ساختار پوشه
```
neon-gamecheck/
├── index.html        صفحه اصلی
├── css/style.css     ظاهر، ساده، انیمیشن‌ها
├── js/data.js        لیست کارت گرافیک‌ها، CPUها، رم‌ها و بازی‌ها
├── js/app.js         منطق مقایسه و نمایش
├── assets/favicon.svg
├── server.py         سرور ساده پایتون
├── start.bat         اجرا در ویندوز (دابل‌کلیک)
└── start.sh          اجرا در لینوکس/مک
```

## اجرا روی شبکه خونه (وای‌فای مودم)
1. پایتون ۳ نصب باشه.
2. ویندوز: روی `start.bat` دابل‌کلیک کن. لینوکس/مک: `./start.sh`
3. آدرسی که چاپ میشه مثل `http://192.168.1.10:8080` رو از هر گوشی/لپ‌تاپ متصل به همون مودم باز کن.
4. اگه باز نشد، فایروال ویندوز رو برای پورت 8080 اجازه بده.

## دسترسی از بیرون (اینترنت)
- تو پنل مودم (معمولاً 192.168.1.1) بخش Port Forwarding: پورت 8080 → آی‌پی داخلی کامپیوترت پورت 8080.
- بعدش با `http://آی‌پی-عمومی-تو:8080` باز میشه. (اگه آی‌پی ثابت نداری از DDNS استفاده کن.)
- هشدار امنیتی: سایت استاتیکه و ریسکش کمه، ولی کامپیوتر رو همیشه آپدیت نگه دار.

## اضافه کردن بازی یا قطعه
فقط فایل `js/data.js` رو ویرایش کن.
- بازی: `["اسم",حداقل گرافیک,حداقل CPU,حداقل رم,حداقل VRAM,پیشنهادی گرافیک,CPU,رم,VRAM]`
- گرافیک: `["RTX 4070 12GB", امتیاز, VRAM]` — امتیازها نسبی‌ان (GTX 1060 6GB ≈ 32، RTX 4090 ≈ 280).
